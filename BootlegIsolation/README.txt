IT-266-004 Midterm - Tanib Momen
Common Deliverable #1

INSTALLATION - 
	
1. Place mod folder into your root Quake 4 folder.
2. Open Quake 4.
3. Navigate to the "mods" tab on the bottom.
4. Select "BootlegIsolation".



This is a Quake 4 mod where you are stuck in a building with an unkillable gladiator. The goal is to survive as long as possible in the given level.

To aid you in this, you will have an arsenal of weapons to deter the monster. Whether its slowing them down, obfuscating yourself, and pushing them back. 

There are materials scattered across the level that you can use to craft items. Access the crafting menu with B.

If you would like to read this in-game, press TAB to open the HELP menu. 

Enjoy!
